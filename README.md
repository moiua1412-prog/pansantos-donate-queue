# Donate Queue v2

เวอร์ชันนี้ไม่ใช้ `better-sqlite3` จึงไม่ต้องติดตั้ง Python หรือ compiler และทำงานกับ Node.js รุ่นใหม่ได้ง่ายกว่า

## เปิดใช้งาน
เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน:

`npm.cmd install`

จากนั้น:

`npm.cmd start`

เปิด Chrome ที่:

`http://localhost:3000`
